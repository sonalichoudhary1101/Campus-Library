# Library Manager (HTML/CSS -> GraphQL -> MySQL)

Full CRUD: create, read, update and delete books, authors and genres.

1. Put your MySQL password in db.js
2. mysql -u root -p < schema.sql   (only for a fresh database - it recreates gqldemo)
3. npm install
4. node server.js                  (http://localhost:4000/)
5. VS Code: right-click public/index.html -> Open with Live Server
